# 药方

当前版本 1.8.5，合并用户提供的药方 1.8.3 与本地 yyawf 0.0.15 改动，按 MPL-2.0 发布。

完整功能、设置入口、权限与限制见 [使用说明](DESCRIPTION.md)。

## 功能

- 清理微博主页和搜索页的广告、推广热搜、导航、侧栏及身份图标。
- 按关键词过滤微博、转发原文、评论与热搜，支持 TXT 追加导入、去重和导出。
- 保留旧版本地作者名单，支持添加数字 UID 或微博主页链接；名单不会修改微博原生黑名单。
- 同步微博原生黑名单，校验账号及分页完整性，失败时保留上次缓存；仅计入屏蔽范围全选的用户。
- 保留“经常访问的超话”清理，默认开启，可即时关闭恢复。
- 默认隐藏左栏自定义分组和信息流顶部横幅；可分别在“界面清理 → 左栏”和“界面清理 → 微博内容”关闭对应清理项，保留默认导航、发微博区域和正常微博。
- 支持收藏标签折叠、取消固定，以及右栏清空后加宽中间栏。
- 设置按账号保存，修改即时生效；账号切换时取消旧请求并重新应用对应配置。

“默认进入最新微博”默认关闭。启用后，仅首次直接打开首页时跳转；站内首页链接、详情页和带参数或 hash 的地址保持原有行为。

本地作者过滤保留旧版例外：直接访问该作者主页时保留其内容，“@我的”评论不使用本地作者及关键词过滤；微博原生黑名单仍生效。

## 安装与升级

将本仓库的 [药方.user.js](药方.user.js) 导入用户脚本管理器，或用其完整内容替换现有脚本后保存。通过脚本管理器菜单“药方设置”或页面内设置入口配置。

保留原作者署名、上游命名空间及 CONFIG 数据格式，兼容同一脚本存储中的旧作者名单，并迁移 home::newest 和旧推广热搜开关。新键优先，其他账号和未知配置保持不变。脚本已更名为“药方”；改名或新建安装可能使用不同存储，升级时请确认替换的是原有安装，跨安装迁移需在脚本管理器中处理。

此合并版禁用自动更新，避免被粘贴脚本中的第三方更新地址覆盖；后续手动升级本仓库脚本。

## 开发验证

需要 Node.js 20 或更新版本。核心测试不依赖第三方包：

    npm run check
    npm test

浏览器回归测试使用 Playwright：

    npm install
    npx playwright install chromium
    npm run test:browser

如本机已安装 Chrome，也可使用：

    YYAWF_BROWSER_CHANNEL=chrome npm run test:browser

浏览器测试在本地构造微博页面并模拟 GM 存储和黑名单接口，拦截全部网络请求；不会访问真实微博账号。覆盖动态内容、搜索页、配置迁移、恢复显示、账号切换、黑名单异常和首页导航。线上 DOM 与接口仍可能变化，需要实际页面验证。
